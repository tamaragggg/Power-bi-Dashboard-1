# 📊 Sales Dashboard using Power BI

## 📌 Project Overview

This project is an end-to-end data analysis dashboard created using Power BI. It focuses on analyzing sales data to generate meaningful insights and support business decision-making.

## 🎯 Objectives

* Analyze overall sales performance
* Identify top-performing products and regions
* Understand customer trends and behavior
* Track profit and revenue growth

## 🛠️ Tools & Technologies Used

* Microsoft Power BI
* Power Query (Data Cleaning & Transformation)
* Excel / CSV Dataset

## ⚙️ Process Followed

1. Imported raw dataset into Power BI
2. Cleaned and transformed data using Power Query
3. Created relationships in the data model
4. Built calculated columns and measures using DAX
5. Designed an interactive dashboard with visuals
